## Notes

- The agent generates cases in batches and never moves to the next batch without approval.
- If the agent finds a behavior not covered by any AC or journey, it pauses and flags it to the Lead rather than inventing a test case.
- Custom fields (`environment`, `priority`, `automation`) can be added freely to any test case — the format is flexible.
- Test case IDs use the prefix in `specos-outputs.yml` (default: `TC`). Change the prefix there before generating if your tool uses a different format.
