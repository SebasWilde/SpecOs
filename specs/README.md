# specs/

This folder contains your project features.

Each feature has its own folder with:

```
[feature-name]/
├── spec.md        ← everything: journeys + ACs + technical
├── tasks.md       ← subtasks by role
└── CHANGELOG.md   ← spec change history
```

To create a new feature, use the prompt `prompts/01-collaborative-session.md`.

See `examples/feature-tags/` for a complete end-to-end example.
